# lexicon2026-grupp4-torsdag
Gruppuppgift för torsdag eftermiddag

Projektbeskrivning:

Detta projekt fungerar som en offentlig portal till
mer information om hur man sågar upp en isvak och
även vart det finns isvakar runt om i landet.

Funktioner:

Kolla vart det finns isvakar i Sverige, sökbar.
Information om varje isvak.


Instruktioner:

Välj eller sök efter en isvak någonstans i Sverige.
